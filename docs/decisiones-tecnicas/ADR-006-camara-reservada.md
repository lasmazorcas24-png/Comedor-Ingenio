# ADR-006: Cámara reservada para fase futura
**Estado:** Aprobado
**Decisión:** No se desarrolla. Se reservan tablas `camara_eventos` y `camara_conciliacion` y un contrato de evento (platillo detectado, hora, confianza) para comparar contra ventas y caja. Las tarjetas de cámara de los diseños quedan ocultas tras una bandera de configuración.
