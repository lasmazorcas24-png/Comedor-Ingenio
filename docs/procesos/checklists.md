# Checklists digitales

## Motor genérico
`plantilla` → `items` → `ejecución` → `respuestas`. Los formatos físicos (limpieza, apertura, cierre, control operativo) se cargan como datos, sin código nuevo por formato.

## Tipos de ítem
Sí/No · Número (con rango) · Texto · Foto opcional · Selección.

## Mejoras sobre el papel
- Hora y usuario automáticos.
- Ítem obligatorio bloquea el cierre del turno si queda vacío.
- Valores fuera de rango generan alerta.
- Historial consultable por fecha y responsable.
