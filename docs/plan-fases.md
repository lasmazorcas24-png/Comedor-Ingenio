# Plan de desarrollo por fases

| Fase | Contenido | Resultado |
|---|---|---|
| 0 | Repositorio, estructura, documentación aprobada | Base lista |
| 1 | API, auth, roles, auditoría, marco PWA, navegación móvil | Login y esqueleto por rol |
| 2 | Turnos, ventas, caja | Operación diaria básica |
| 3 | Producción y pantalla de cocina | Corte, uso, diferencia |
| 4 | Inventario, recetas, costos, pedidos internos | Ciclo de insumos completo |
| 5 | Checklists, alertas, notificaciones | Control operativo |
| 6 | Dashboards y reportes de socios, participación | Vista administrativa |
| 7 | Piloto, ajustes, endurecimiento | Producción estable |
| 8 | Cámara (futuro) | Conciliación visual |

Criterio de cierre de fase: módulo probado, documentado en `docs/modulos/`, entrada en `CHANGELOG.md`.
